# TokenOptim: Quick Start Guide ⚡

Get up and running in 2 minutes.

## 🚀 Installation (30 seconds)

### Step 1: Download
Clone or download this repo:
```bash
git clone https://github.com/adifydigitalnoida-del/tokenoptim.git
```

### Step 2: Load in Chrome
1. Go to `chrome://extensions/`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked**
4. Select the `tokenoptim-repo` folder
5. Done! ✅

### Step 3: Open TokenOptim
Click the TokenOptim icon in your Chrome toolbar.

---

## 💡 First Use

### On Claude.ai
1. Open claude.ai
2. Type your prompt
3. TokenOptim shows token count in real-time
4. Click **Preview Compression** to see savings
5. Send message when ready

### On ChatGPT / Gemini / Grok / Kimi / GLM
Same flow - works on all 6 platforms!

---

## 🎯 Key Features

| Feature | What It Does |
|---------|-------------|
| **Token Counter** | Shows real-time token count |
| **Compression** | Remove filler words, save 15-30% |
| **Cost Tracking** | See USD cost per prompt |
| **Caching** | Reuse similar prompts (saves $) |
| **Dashboard** | View stats + settings |

---

## ⚙️ Settings

Click the TokenOptim icon → **Settings** to:
- Enable/disable compression
- Choose accuracy mode (API/LIVE/~Est)
- Export CSV stats
- Clear cache
