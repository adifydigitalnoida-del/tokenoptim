## 📁 Groq Helper Script

**File:** `groq-dev-helper.js`

**Usage:**
```bash
# Set API key
export GROQ_API_KEY=your_groq_api_key_here

# Run development cycle
node groq-dev-helper.js
```

**Functions:**
- `generateSemanticCachingCode()` - Generate caching logic
- `generateTokenCounterCode()` - Generate token counting
- `generateDocumentation(topic)` - Generate docs
- `callGroq(prompt)` - Raw API call
